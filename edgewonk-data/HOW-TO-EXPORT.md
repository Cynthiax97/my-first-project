# How to Export from Edgewonk

## Steps

1. Open Edgewonk
2. Go to the **Trade List** view
3. Click the **Export** button (usually top-right area)
4. Choose **CSV** format
5. Select the date range you want to analyze
6. Save the file into THIS folder (`edgewonk-data/`)
7. Name it something descriptive like `trades-2026-september.csv`

## Tips

- Export monthly files for easier tracking over time
- You can have multiple CSV files in here — Claude will read them all
- Don't worry about the exact column names; Claude will figure them out
- If you use custom fields in Edgewonk, they'll come through in the export too
